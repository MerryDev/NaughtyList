# NaughtyList

NaughtyList verbindet die Moderation eines Minecraft-Netzwerks in einem zentralen System. Vom eingehenden Report über Beweise und Fallbearbeitung bis zur Strafe bleiben alle Vorgänge serverübergreifend einheitlich und nachvollziehbar.

## Features

- Zentrale Spielerprofile mit Namensverlauf und Discord-Verknüpfung
- Serverübergreifende Reports mit Gründen, Replays und Statusverwaltung
- Moderationsfälle mit Zuweisung, Notizen und Beweisen
- Rollenbasierte API-Zugriffe für Server und Moderatoren
